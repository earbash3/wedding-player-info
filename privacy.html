Privacy Policy

Wedding Player is a private, non-commercial application for one wedding event. It runs on the organiser's Mac and is available only to invited guests on the same local network.

Information processed

The application processes a guest-chosen nickname, song searches, submitted YouTube video links, queue actions and quiz answers. It may also process basic technical information needed for security and rate limiting, such as a temporary device identifier and local network address.

YouTube API Services

Wedding Player uses YouTube API Services for video search and playlist metadata, and the standard YouTube IFrame Player for playback. By using these features, users also agree to the YouTube Terms of Service. Google's handling of information is described in the Google Privacy Policy.

Wedding Player does not use Google OAuth, does not request access to a user's Google or YouTube account, and does not collect YouTube account credentials. It does not download, extract, proxy, alter or store YouTube media.

Purpose and legal basis

Information is used only to operate the shared queue, enforce guest limits, moderate requests, restore event state and maintain the reliability and security of the application during the private event. The processing is based on the organiser's legitimate interest in operating the event service and the guest's voluntary use of it.

Storage, sharing and retention

Event data is stored locally on the organiser's Mac. It is not sold, used for advertising or shared with unrelated third parties. Requests sent to YouTube and Google are subject to their respective policies. Temporary event data and YouTube API metadata caches are deleted when no longer needed for the event, policy compliance or troubleshooting. Cached YouTube metadata is refreshed or deleted in accordance with YouTube API Services policies.

Deletion and user choices

A guest may ask the event organiser to remove their nickname, pending requests or quiz data. Because the client does not use Google OAuth, there is no Google authorisation token to revoke. Guests may stop using the client at any time by closing the page.

Security

Administration is PIN-protected, state-changing requests are authorised by the local server, and playback-host capability is restricted to the trusted Mac. No internet service can guarantee absolute security.

Contact

Privacy and deletion requests can be directed to the event organiser through the invitation contact channel or through the public repository's issue tracker.
