Private event software

A lightweight wedding jukebox for invited guests.

Wedding Player runs on the organiser's Mac and lets guests on the same local network search for songs and submit requests from their phones.

One trusted playback host

Audio and video play only in the organiser's visible browser. Guest phones act as remote controls and never become playback hosts.

Guest requests

  1. Search for an embeddable video1
  2. Add it to the shared queue2
  3. Playback via the official player3

YouTube integration

Search uses the documented YouTube Data API. Playback uses the standard, visible YouTube IFrame Player. Wedding Player does not download, extract, proxy, alter or store YouTube media and does not block advertisements.

Open YouTube

Data minimisation

Guests use a temporary nickname. The application does not require a Google Account, OAuth access or access to a guest's YouTube account. Local event data stays on the organiser's Mac.

Private access

The application is not a public streaming service. Only invited guests connected to the event's local network can reach the live client.
